BY CRACI

CRACI Platform
Resources Every team gets free access to the CRACI platform for the whole event, CI/CD build minutes included. CRACI runners are GitHub Actions compatible, so you can keep your existing workflows and switch a job over in one line. As your builds run, CRACI records every external dependency they pull in and produces verifiable CycloneDX SBOMs, including packages restored from caches, and AI fixes can patch vulnerabilities automatically based on that exact build data. Everything is open to you through the CRACI API, and our docs ship with agent skills so you can work with them in your AI coding tools. Our whole team is on site to help you get set up and to go deep on supply chain security. List of technologies that we are bringing: – Free access to the CRACI platform during the event (platform.craci.com) – CI/CD build minutes on CRACI's GitHub Actions-compatible runners – Build-time CycloneDX SBOMs with completeness data per job and per cache – AI fixes: automated vulnerability fixes grounded in exact build data – The CRACI API: SBOMs, OCI image and cache provenance, network traces, job logs and compute usage – Documentation, examples and agent skills: https://docs.craci.com/ – Five mentors from the CRACI team on site all weekend Claim your free compute Every team gets 1000€ credits to the CRACI platform for the whole event. These can be used for CI/CD or any compute need you require. Setup takes about ten minutes. 1. Get your invite code You need the Junction invite code to create your team's organization on CRACI. Get it either way: Discord: Ask in the #craci channel on the Junction Discord. CRACI booth: Come say hi. We'll give you the code and help with setup on the spot. Only one person per team needs to do steps 2 to 4. Invite your teammates afterwards. 2. Sign up and create your organization Go to platform.craci.com and sign up. Create an organization for your team and enter the Junction invite code. 3. Connect GitHub In CRACI, go to Settings → Builds and start the Install GitHub flow. CRACI walks you through creating its GitHub App and installing it on your GitHub organization or account. Grant the App access to the repositories you'll build: all repositories, or a selected set. Wait until the connection shows configured. You can change repository access later on GitHub under Settings → GitHub Apps → CRACI → Configure. 4. Run your first build on CRACI After connecting the app, any workflow file with runs-on: craci will be running on the CRACI platform. The default runner size is 2 vCPUs and 6GB RAM. jobs: build: runs-on: craci steps: - uses: actions/checkout@v4 - run: make build Push, and the job runs on CRACI. Open the build in the platform to see what it pulled in. Need a bigger machine? Add the setup step first: steps: - uses: cracicorp/setup@v1 with: size: "8" # 1–32 units; each unit is 1 vCPU and 3 GB RAM. Default is 2. - uses: actions/checkout@v4 You can also point your agent at our migration skill for migrating old workflows or when creating new ones: https://docs.craci.com/skills/craci/SKILL.md 5. Get an API token An organization admin can create a token under Settings → API tokens. The token is shown only once, so store it somewhere safe. Call the API at https://api.craci.com with Authorization: Bearer $CRACI_API_TOKEN. The full OpenAPI spec is at api.craci.com/openapi.json . Resources If you or your agent needs more info, check out docs.craci.com or come yap with us at the booth! (3rd next to the stage)

BY IRONSHARD

IronShard (Datasets for other challenges)
What is IronShard? IronShard is a next-generation cloud object storage service built for developers and AI agents. Its key features include: AI-native storage: Access and manage the same buckets using AI agents through MCP or traditional applications through the S3-compatible API. Zero-copy bucket forking: Instantly create independent, writable branches of existing datasets without duplicating the underlying data. Intelligent multi-cloud storage: Data is encrypted, erasure-coded, and distributed across a global mesh of 200+ storage regions operated by 10+ providers, with automatic optimization of placement, redundancy, performance, and costs. How can you use IronShard during the hackathon? IronShard provides several ways to work with challenge data and build your solutions: Access challenge datasets: Where applicable, input data is preloaded into read-only IronShard buckets. Fork datasets with one click: Create your own writable bucket from a challenge dataset, instantly and without copying the original data. Create your own buckets: Create as many additional buckets as you need for your solution. Connect AI agents and S3 tools: All buckets (read-only, forked, or manually created) are accessible through MCP for AI agents and through standard S3-compatible tools and libraries. Store and submit large artifacts: If your solution includes trained AI models, datasets, or other files too large for a regular GitHub repository (which allows max 100 MiB per file), store them in an IronShard bucket. Include the bucket and object references in your submission. Hackathon judges will be given read access to these artifacts.

BY QUALIA

Qualia Platform
What you can do with the Qualia platform? Recorded episodes and not sure which ones are worth training on? A few bad takes can quietly drag a whole model down. Qualia helps you find them fast, so you train on your best data. Upload your dataset: collect data with the SO-101 arms or Rokoko motion capture, then upload it to the Qualia platform. Check every episode: quality checks flag failed takes, timing issues and inconsistent demos, so you don't have to watch every recording. Curate: keep the good episodes and drop the rest. Every curated set is saved as a version, so you always know exactly what trained your model. Export and train: download your curated dataset and train your policy, e.g. pi0.5 with LeRobot. About Qualia Qualia is a robot learning company from Copenhagen. We help teams train robots on real tasks: collecting demonstrations, curating the data, training, and deploying on the robot. Our product, the Qualia platform, shows you which recorded episodes will make your robot better and which will quietly make it worse. The better your data, the better your robot, and with Qualia you see exactly what goes into every model you train.

Scailab builds tools for creating computer vision models quickly and in a controlled way for robotics, industrial automation and autonomous systems. Our platform, Scaipipe, covers the full loop in one place.
